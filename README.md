# 내 자산관리 v5

핵심 구조를 '계획 → 실행 체크 → 월별 소비 → 누적 자산 성장'으로 재설계했습니다.

주요 기능
- 기존에 이미 모은 자산을 여러 항목으로 입력
- 월별 저축/투자 계획 수립 및 수정
- 계획 달성 체크리스트
- 체크한 금액만 누적 자산형성으로 반영
- 월별 실제 월급 입력 + 추가수입
- 110만 원 생활비 가계부와 카테고리별 지출
- 월간 돈 흐름: 수입 / 생활비 / 자산형성 / 미배분
- 누적 자산 추이 그래프
- 월별 결산: 완료한 계획과 소비처 확인
- 연도 제한 없는 월 이동
- v3/v4 브라우저 데이터 자동 이전 시도
- JSON 백업/복원
- PWA 홈 화면 설치 지원

자산 계산
총 추적 자산 = 기존 자산 + 월별 체크리스트에서 완료한 저축/투자/CMA/연금 금액
